# Privacy Policy for PII Copy Shield

Effective date: October 17, 2026

PII Copy Shield processes selected text locally in the browser when a user copies it. It replaces recognized email addresses, phone numbers, Indian mobile numbers, Indian PAN and Aadhaar numbers, payment card numbers, and IPv4 addresses with placeholders before the text reaches the clipboard.

## Data collection and transmission

PII Copy Shield does not collect, store, sell, or transmit clipboard contents, selected text, browsing history, page contents, personal information, analytics, or identifiers. It does not use remote servers, external scripts, advertising, or tracking.

The extension stores only the user's detection-rule preferences using the browser's extension storage API. These preferences remain in the user's browser and are not transmitted to the developer.

## Changes

Changes to this policy will be published with a new extension version. Questions can be raised through the support contact listed on the Mozilla Add-ons page.
